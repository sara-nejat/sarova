## 🛍️ About

**Sarova** is a modern fashion storefront landing page. It brings together
curated brands across clothing, shoes and accessories in a clean, elegant,
mobile-friendly interface with a signature burgundy look.

## ✨ Features

- 🎨 **Elegant burgundy theme** with a bold editorial hero section
- 📱 **Fully responsive** thanks to Bootstrap's grid and collapsible navbar
- 🧭 **Clear navigation** with Home, New Arrivals, Popular, Clothing, Shoes, Accessories and Support
- 🏷️ **Featured brands** section
- ⚡ **Fast and lightweight**, built as a static site

## 🚀 Run Locally

```bash
# Clone the repository
git clone https://github.com/sara-nejat/sarova.git

# Go to the project folder
cd sarova

# Open index.html in your browser
# or use a local server, for example:
npx serve
```
